# CHROMAFALL

Neon Tetris in the CHROMA series visual language (CHROMALINE / CHROMABLOCKS).
React 18 + Vite 5 — single page, deployable anywhere static.

## Controls
- ← → / A D — move (hold to auto-repeat)
- ↑ / W / X — rotate CW · Z — rotate CCW
- ↓ / S — soft drop · Space — hard drop
- C / Shift — hold · P — pause
- On-screen buttons mirror the same actions (hold-to-repeat on move / soft).
